## From the game (iOS)

Tap **Feedback** on the bottom bar → opens this tracker in Safari (you can switch Bug / Improvement).

## Labels

- `bug` — broken behavior
- `improvement` — ideas / UX / balance
- `ios` — noticed while playing on iPhone/iPad
- `balance` — difficulty / economy tuning
- `ux` — controls / readability
